# دليل التقويم الذاتي المدرسي — نسخة سطح المكتب (ويندوز + ماك)

برنامج يعمل **دون إنترنت إطلاقاً**؛ كل الشواهد والبيانات تُحفظ على الجهاز نفسه.
(4 مجالات · 11 معياراً · 52 مؤشراً · 162 شاهداً — مأخوذة من المشروع الأصلي.)

## الطريقة الأسرع (بدون تثبيت)
افتح ملف **التقويم-الذاتي-دون-انترنت.html** بأي متصفح (Chrome / Edge / Safari) على ويندوز أو ماك.
يعمل دون إنترنت، وتُحفظ البيانات داخل المتصفح. خذ نسخة احتياطية دورية من «الإعدادات».

## بناء البرنامج المثبَّت (.exe و .dmg) — مرة واحدة فقط
المتطلب: تثبيت **Node.js (LTS)** من https://nodejs.org والاتصال بالإنترنت أثناء البناء فقط.

- **ويندوز:** انقر مرتين على `build-windows.bat` ← يظهر المثبّت داخل مجلد `dist` (ملف Setup‎.exe).
- **ماك:** (على جهاز ماك) انقر بالزر الأيمن على `build-mac.command` ← فتح. يظهر ملف `.dmg` داخل `dist`.
  إن لم يعمل: افتح Terminal داخل المجلد ونفّذ `npm install && npm run dist:mac`.
- **بدون ماك؟** ارفع المجلد إلى مستودع GitHub ثم Actions ← Build installers ← Run workflow؛
  سيبني المثبّتين (ويندوز وماك) سحابياً وتنزّلهما من Artifacts.

للتجربة دون بناء: `npm install` ثم `npm start`.

## ملاحظات
- البرنامج غير موقّع رقمياً: في ويندوز اختر «مزيد من المعلومات ← تشغيل على أي حال»،
  وفي ماك (إن نُقل من جهاز آخر) اضغط بالزر الأيمن ← فتح، أو نفّذ `xattr -cr /Applications/SelfEvaluation.app`.
- مكان البيانات يظهر في «الإعدادات»، ويمكن فتحه بزر واحد. النسخ الاحتياطي/الاستعادة من الإعدادات أيضاً.
- لتعديل المؤشرات أو الشواهد الافتراضية: عدّل `renderer/data.js`.
- لتغيير الألوان: متغيرات `:root` أعلى `renderer/styles.css`.
- الخط: يستخدم خطوط النظام العربية (Segoe UI / SF Arabic)؛ وإن ثبّتَّ خط Tajawal على الجهاز سيُستخدم تلقائياً.
- ملفات الشواهد المدعومة: PDF، Word، Excel، PowerPoint، الصور (حتى 50 م.ب للملف).
